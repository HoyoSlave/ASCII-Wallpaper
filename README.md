# ASCII Wallpaper (Android)

Aplikasi Android minimalis yang mengonversi gambar, GIF, dan video menjadi seni ASCII menggunakan font `monospace` bawaan perangkat.

## Fitur & Spesifikasi
- **Pilihan Density Karakter**: Slider *Density* dengan nilai `2, 3, 4, 6, 8, 12, 16, 24, 32, 48, 64, 96, 128, 192, 256`.
- **Mode Teks Berwarna atau Monokrom**: Opsi `Colored text` untuk beralih antara karakter ASCII berwarna (RGB) atau putih monokrom di atas latar hitam dengan posisi dan ukuran karakter yang 100% identik di semua tingkat *density*.
- **Font Monospace Bawaan HP**: Menggunakan `Typeface.MONOSPACE` bawaan sistem Android dengan proporsi karakter asli.
- **Lokasi Penyimpanan Terpadu (`Download/ASCIIWallpaper`)**:
  - `Import media`: Memilih gambar, GIF, atau video.
  - `Save to gallery`: Menyimpan hasil gambar (`.png`) atau animasi video 16 FPS (`.gif`) ke `Download/ASCIIWallpaper`.
  - `Save TXT` / `Save ZIP`: Menyimpan teks ASCII (`.txt` untuk gambar, atau arsip `.zip` berisi `1.txt`, `2.txt`, dan seterusnya sesuai frame untuk video/GIF) ke folder yang sama di `Download/ASCIIWallpaper`.
